## Engineering focus

### Mobile

- Production Flutter applications shipped to Android and iOS from one codebase
- Predictable state with Riverpod and Provider, local caching, and background sync
- Firebase Authentication, Firestore, Cloud Storage, push notifications, and crash reporting
- Interfaces that stay responsive on slow connections and recover cleanly from failure

### Backend

- REST APIs in Node.js and Spring Boot with versioned, documented contracts
- Relational schema design in PostgreSQL and MySQL, including migrations and indexing
- Asynchronous processing over Kafka and RabbitMQ with retries and idempotent handlers
- Containerised builds and deployments through Docker and GitHub Actions

### Applied AI

- Gemini and Grok APIs integrated into product features, not bolted on as demos
- Structured output with schema validation, timeouts, and deterministic fallbacks
- Prompt iteration measured against real cases rather than impressions
- AI-assisted development used for speed, with the same review bar as any other code
